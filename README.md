# Objetivo

El objetivo de la aplicación es brindar información relativa al mundo del fútbol, obteniendo información desde una API externa como fuente de datos y permitiendo, mediante endpoints propios, el alta, baja y modificación de la misma. A partir de estos datos, el usuario que ingrese a la aplicación podrá:

- Acceder a información sobre clubes, jugadores y competiciones.
- Armar una formación con los jugadores que haya en el plantel actual de un club. La formación podrá descargarse como imágen.

Respaldo y Restauración de Base de Datos PostgreSQL - FootData

Este documento explica cómo realizar una copia de seguridad (backup) y cómo restaurarla (restore) para la 
base de datos `footdata_db` utilizada en el proyecto Full Stack FootData.

Desde la terminal con `pg_dump` y `psql`

🢃 Realizar un respaldo (backup)

1. Abrir una terminal con PostgreSQL en el PATH (o desde la carpeta de instalación).
2. Ejecutar:

```bash
pg_dump -U postgres footdata_db > backup_footdata.sql
